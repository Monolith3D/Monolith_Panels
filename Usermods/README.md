# User Mods

This folder is for community-made additions, adaptations, and compatibility parts for Monolith Panels.

User mods are not official Monolith Panels files unless stated otherwise. Check the mod author, target printer, panel thickness, door or hinge assumptions, clip style, and clearance assumptions before printing or ordering parts.

Use the folder structure `username/usermod_name` for new user mods.

Good user mod folders should include:

- A short `README.md` explaining what the mod does
- Clear compatibility notes for the target printer, panel dimensions, panel thickness, clip style, and door or hinge setup where relevant
- STL, CAD, image, and BOM files needed to understand the mod
- Assembly notes or warnings if the mod changes panel fit, clips, hinges, handles, door closure, foam stack, or clearance
- Credit and license notes when the mod reuses work from another project

Use user mods at your own risk. They may not receive updates when the main Monolith Panels files change.
